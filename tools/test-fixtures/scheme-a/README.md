# Accepted Scheme A oracle

Copied unchanged from the completed `scheme-calibration` study at checkpoint
`30794ef`. `hashes.json` authenticates the imported inputs, measurement records
and images. These expected values are not regenerated by the production runner.

- `fixtures.json`: four Scheme A and four unchanged Scheme B cases.
- `probe-results.json`: original current/candidate measurements, dense cases and
  explicit-break checks. B candidate records are historical evidence ONLY and
  are deliberately not used as the production oracle.
- `*-candidate.png`: the four accepted Scheme A renders, at 2x.
- `*-current.png`: the four unchanged Scheme B controls, at 2x.
- `production-hashes.json`: source-file fingerprints from the original study.

Run `node_modules/electron/dist/electron.exe tools/scheme-a-production.cjs` from
the project root after installing its dependencies. The test needs Git checkpoint
`30794ef` for before/after renders, plus the repository's existing fonts/assets.
No AppData/Temp calibration input or untracked diagnostic study is required.
Electron's isolated browser profile is temporary; final output is persistent.
